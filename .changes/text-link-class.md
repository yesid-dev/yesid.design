Add the `text-link` class to `base.css`. A link that also needs layout classes, such as `class="text-link inline-flex min-h-11"`, now gets the classless text link look: `--primary` ink, a 1px underline at 0.2em, 2px on hover, and the same forced-colors behavior. Links without a class and component links are unchanged.
