`SectionHeading` takes `size="title"` for the compact title of a task or reading screen: the `--text-title` size, bold, with normal letter spacing, and a subheading in the sentence-case reading label type instead of the mono uppercase label. The `dot`, `number`, `headingAccent`, `explainer` and `level` props work the same, and the root carries `data-size="title"`. The default `size="display"` renders exactly as before, so no migration is needed.
